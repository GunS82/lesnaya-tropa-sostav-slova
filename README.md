# Лесная тропа знаний: состав слова

**Играть онлайн:** https://guns82.github.io/lesnaya-tropa-sostav-slova/

Отдельный большой модуль для 2 класса. Ребёнок знакомится с четырьмя хранителями слова: Приставкой, Корнем, Суффиксом и Окончанием. Задача не только найти части слова, но понять, зачем каждая нужна и что происходит, когда она меняется.

Материал опирается на страницы 57–67 учебника В. П. Канакиной и В. Г. Горецкого, «Русский язык», 2 класс, часть 1.

Другие тропы остаются отдельными играми:

- [Предложение](https://guns82.github.io/lesnaya-tropa-znaniy/)
- [Слова и их значения](https://guns82.github.io/lesnaya-tropa-slova/)
- [Звуки, буквы и алфавит](https://guns82.github.io/lesnaya-tropa-zvuki-bukvy/)

## Как открыть

```powershell
python -m http.server 8080
```

Затем откройте http://127.0.0.1:8080/

Проверка заданий:

```powershell
node js/check-logic.js
```

Прогресс этого модуля хранится отдельно, ключ `forestWordPartsProgress`.

## Что внутри

29 заданий на карте из пяти глав, затем финальное испытание из 25 коротких проверок.

1. Корень — семья слова, общий смысл, похожие буквы ещё не родня.
2. Окончание — форма слова, нулевое окончание и слова без окончания.
3. Приставка — стоит перед корнем и меняет смысл действия.
4. Суффикс — стоит после корня и создаёт новое слово.
5. Вся команда — полный разбор, конструктор и «сломанная машина слов».

Имя персонажа приставки — школьный термин **Приставка**.

Картинки лежат в `assets/scenes/` и `assets/characters/`. Если файла нет, на карточке остаётся эмодзи. Подписи пишет страница, не сам рисунок.
